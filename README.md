# About Me Portfolio

A premium, futuristic personal portfolio built with React, Vite, TailwindCSS, Framer Motion, and GSAP.

## Features

- Full-screen hero with animated intro and call-to-actions
- Glassmorphism cards with neon gradient accents
- Scroll-based reveal animations and timeline motion
- Interactive skills meters and project showcase cards
- Animated contact form and social links
- Responsive layout for desktop, tablet, and mobile

## Tech Stack

- React
- Vite
- TailwindCSS
- Framer Motion
- GSAP + ScrollTrigger
- Lucide React

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
